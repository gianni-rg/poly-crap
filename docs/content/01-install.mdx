## Installer (macOS and Linux)

```sh
curl --proto '=https' --tlsv1.2 -LsSf \
  https://github.com/drew-simmons/poly-crap/releases/\
latest/download/poly-crap-installer.sh \
  | sh
```

:::note
The installer downloads a prebuilt release, checks its SHA-256 checksum, and
puts `poly-crap` in `~/.cargo/bin`. Archives and checksums are also on
[GitHub Releases](https://github.com/drew-simmons/poly-crap/releases). To pin
a version, replace `latest/download` with `download/v0.8.0`.
:::

## Installer (Windows)

Run this command in PowerShell:

```powershell
$installer = 'https://github.com/drew-simmons/poly-crap/releases/latest/' +
  'download/poly-crap-installer.ps1'
irm $installer | iex
```

The PowerShell installer is for the `x86_64-pc-windows-msvc` target. It
installs to Cargo's binary directory. If that directory was added to your
`PATH`, restart the shell before running `poly-crap`.

## Cargo

The crate is on [crates.io](https://crates.io/crates/poly-crap). With Rust
1.88 or newer:

```sh
cargo install poly-crap --locked
```

## Build from source

Building from source requires Rust 1.88 or newer:

```sh
git clone https://github.com/drew-simmons/poly-crap.git
cd poly-crap
cargo install --path . --locked
```

## Release targets

| Platform | Architectures |
| --- | --- |
| macOS | Apple Silicon (`aarch64`), Intel (`x86_64`) |
| Linux with glibc | `aarch64`, `x86_64` |
| Linux with musl/Alpine | `x86_64` |
| Windows | 64-bit MSVC (`x86_64-pc-windows-msvc`) |
